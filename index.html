Jarvis AI

A private personal assistant that runs on the owner’s own computer.

About Jarvis AI

Jarvis AI is a personal, single-user assistant. It is not a public multi-tenant cloud product. The software runs locally under the owner’s control and is used for everyday personal tasks such as notes, reminders, and optional Google Calendar lookups.

This website exists so Google OAuth branding can reference a public homepage and privacy policy for the owner’s private Calendar integration. It does not host Jarvis Core or user data.

Google Calendar (optional)

When enabled by the owner, Jarvis may request read-only access to Google Calendar using the OAuth scope https://www.googleapis.com/auth/calendar.readonly. Jarvis does not request permission to create, edit, or delete calendar events through this integration.

Who can use it

Access is limited to the owner’s private setup. There is no public signup and no open service for arbitrary internet users.
