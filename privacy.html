Privacy Policy

Last updated: 9 October 2026

This policy describes how the private Jarvis AI assistant (“Jarvis”) handles information when the owner connects Google Calendar. Jarvis is operated by its owner for personal use and runs primarily on the owner’s local machine.

1. What Jarvis is

Jarvis is a locally hosted personal assistant. This public website does not store assistant data, calendar contents, or OAuth credentials. It only provides branding and privacy information required by Google’s OAuth configuration.

2. Google Calendar access

If the owner enables Calendar integration, Jarvis requests Google OAuth access limited to:

  • https://www.googleapis.com/auth/calendar.readonly (read-only)

With that permission, Jarvis may read calendar metadata and event details needed to answer the owner’s schedule questions. The current integration is designed not to create, modify, or delete Google Calendar events.

3. What is stored locally

On the owner’s computer, Jarvis may store:

  • OAuth client configuration and tokens for Google Calendar access
  • The selected calendar identifier
  • Assistant operational data used by the local installation (for example chat/session state unrelated to this website)

OAuth credential files are kept outside the source-code repository and are protected with restricted local file permissions on Windows where that protection is applied by the setup tools. Application logs are written to avoid recording OAuth client secrets and tokens.

4. Where calendar information may appear

When the owner asks about their schedule, Jarvis retrieves event information from Google’s Calendar API and may include event titles, times, and related details in the answer delivered through the owner’s chosen chat channel (for example Telegram). That means:

  • Google processes Calendar API requests under Google’s terms and policies
  • Schedule answers may be sent to the messaging service the owner uses to talk to Jarvis
  • This website does not receive calendar contents, tokens, or chat messages

5. What this site does not do

  • No advertising trackers or analytics scripts
  • No accounts, sign-in, or data collection forms
  • No hosting of OAuth secrets, tokens, or calendar data

6. How to revoke Google access

The owner can revoke Calendar access at any time by:

  1. Opening Google Account → Third-party access / Your connections to third-party apps and removing access for the Jarvis OAuth app; and
  2. Deleting the local OAuth token files used by the Jarvis installation (and disabling the local Calendar feature if desired).

7. Contact

This is a private personal project. Questions about this policy should be directed to the owner who operates the Jarvis installation and the related Google Cloud OAuth project.
